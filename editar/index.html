Configuración inicial

Se hace una sola vez. Conecta el panel con GitHub para que los cambios se publiquen solos.

  1. Crea un token de GitHub (con la cuenta dueña del repositorio). Abrir GitHub ↗
    ¿Qué elijo en GitHub?
    • Token name: Panel TI Consulting
    • Expiration: la más larga posible (o "No expiration")
    • Repository access: Only select repositories →
    • Permissions → Repository → Contents: Read and write
    • Pulsa Generate token y copia el código que empieza con github_pat_
  2. Pega el token aquí y elige la contraseña que compartirás con el equipo.

El token se guarda cifrado con la contraseña (AES-256). Nadie puede usarlo sin la contraseña.
